# 2026-11-22 — NCN5130 Test 1: Licht schalten

**Frage:** Kommt der NCN5130 mit dem neuen Bring-up hoch, und schaltet ein gesendetes
Gruppentelegramm den Aktor?

**Methode:** XIAO ESP32-C6 an KONNEXTRA BCU light (NCN5130), `examples/BenchTest`
(`KNX_CHIP = KnxTransceiver::Ncn5130`, Debug an), Branch `feature/ncn5130` @ `6fb24da`,
Testkoffer mit Aktor auf 0/1/1. Durchgeführt von Florian, Log aus dem seriellen Monitor.

**Ergebnis: bestanden.** Das Licht schaltet real im 5-s-Takt.
```
[knx] DRV ncn5130 sysstat 0xFB: v20v ok vdd2 ok vbus ok vfilt ok xtal ok, mode normal
[knx] DRV ncn5130 address 1.1.5 confirmed, configure 0x21 (auto-ack on)
[knx] DRV ncn5130 begin: ok, state 0x07
[knx] DRV tx frame: BC 11 05 01 01 E1 00 81 37
[knx] DRV echo 9/9 ok
[knx] DRV con byte 0x8B -> positive
[send] toggle 0/1/1 -> ON (confirmed)
```
(5 Toggles, alle positiv bestätigt, Echo jedes Mal 9/9.)

**Damit bestätigte Datenblatt-Annahmen:** Systemstatus direkt nach Reset = Normal (0xFB);
U_Configure.ind `0x21` mit auto-ack als Antwort auf `F1 11 05 00`; State `0x07`; der NCN5130
echot gesendete Bytes vollständig; `L_Data.con` `0x8B` wie beim TP-UART2.

**Nicht gemessen:** Bring-up-Dauer, Empfangspfad (kein Fremdverkehr ausgewertet, Status-GA
1/1/1 nicht im Log), Busverhalten bei belebtem Bus, ACKs/Wiederholungen, TP-UART2-Pfad nach
dem Umbau (Regressionstest steht aus).
